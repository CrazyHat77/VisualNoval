# vnm-fish-tts-proxy（Fish Audio 本地代理，独立小工具）

## 为什么需要它

Fish Audio 的语音合成接口不支持浏览器直接跨域调用，浏览器会把请求拦下
（CORS 限制）。之前试过借用 SillyTavern 自带的 `/proxy/` 转发，但那条路
需要酒馆的登录会话配合，不同环境表现不一致，容易失败。

这个文件夹是一个完全独立、不依赖酒馆的小工具：一个只有几十行代码、不需要
装任何依赖包的 Node 脚本，跑在你自己电脑上，专门负责把 VN 插件发来的
Fish Audio 请求转发出去，再把语音传回来。全程不经过酒馆的任何机制，也不
经过第三方服务器。

## 怎么用

1. 确认你电脑装了 Node.js 18 或更新版本（酒馆本身能跑起来，Node 版本一
   般就是够的）。
2. 双击这个文件夹里的 `启动.bat`。
3. 会弹出一个黑色命令行窗口，看到类似 `[vnm-fish-tts-proxy] 已启动，监听
   http://127.0.0.1:8765` 的字样就说明成功了。
4. **这个窗口需要一直开着**，你用 VN 插件的 Fish Audio 语音的时候都需要它
   在后台运行。不想用了可以直接关掉这个窗口。
5. 回到浏览器，VN 插件设置里配好 Fish Audio 的 API Key，切换语音源到
   Fish Audio 就能正常用了。

## 自检

浏览器打开 `http://127.0.0.1:8765/status`，看到 `{"ok":true,...}` 就说明
代理已经在正常运行。

## 想让它自动跟着电脑启动（可选）

如果不想每次都手动双击，可以把 `启动.bat` 的快捷方式放进 Windows 的
"启动"文件夹（Win+R 输入 `shell:startup` 回车能打开），这样开机会自动
在后台跑起来。
