 「天气」App 特效文件开发指南（给 AI 的完整 Prompt）
 配套宿主：vnm-weather.json（天气 App，导入到 VN 功能系统里）
 交付物：一个可被「天气」App 导入的 .json 特效文件
════════════════════════════════════════════════════════════════════

你的任务：编写一个「天气」特效文件。天气 App 会在 VN 主界面上叠加一个全屏
透明 canvas，把你写的特效画上去（如下雨、水波纹、雾、落叶等）。一个特效 =
一个 .json 文件，用天气 App 底部「导入」按钮加载。

──────────────────────────────────────────────
一、特效文件结构（必须严格遵守）
──────────────────────────────────────────────
{
  "vnmWeatherEffect": true,          ← 必须，标识这是天气特效文件
  "name": "下雨",                     ← 卡片显示名
  "version": "1.0.0",
  "description": "一句话说明（会显示在卡片展开处）",
  "params": [                        ← 可调参数，App 会渲染成滑块「仪表盘」
    {"key":"intensity","label":"雨量","min":1,"max":10,"default":4,"step":1},
    {"key":"size","label":"大小","min":50,"max":200,"default":100,"step":5,"unit":"%"}
  ],
  "code": "(function(api){ ... return {frame:frame, clear:clear, resize:resize}; })"
}

- params 每项：key（代码里 api.params[key] 读取）、label（显示名）、min/max/
  default/step（滑块范围）、unit（可选，仅显示）。用户拖动滑块即时改变
  api.params[key]，你的 code 每帧读取即可做到「实时可调」。
- code 是「字符串化的函数表达式」，必须用 (function(api){ ... }) 包裹，且
  return 一个实例对象（见第三节）。宿主用 new Function('api','return('+code+')(api)')
  执行，所以：ES5 风格（var/function）、不要用反引号模板字符串、不要 async/await。

──────────────────────────────────────────────
二、api 对象：宿主提供给特效的一切
──────────────────────────────────────────────
code 收到的 api 包含：
  api.canvas     本特效专属的 <canvas>（已铺满全屏，透明背景）
  api.ctx        canvas 的 2D 上下文（已按 devicePixelRatio 做好缩放，
                 你直接用 CSS 像素坐标画即可）
  api.width      画布宽（CSS 像素）
  api.height     画布高（CSS 像素）
  api.dpr        设备像素比
  api.params     当前参数值对象 {key:value}（用户调滑块会实时变）
  api.pointer    全屏指针状态（相对主界面左上角的坐标）：
                 {x, y, px, py, vx, vy, down, t, moved}
                 x/y=当前坐标，px/py=上一帧坐标，vx/vy=速度，
                 down=是否按下，moved=最后一次移动的时间戳(ms)。
                 判断「鼠标正在动」：api.now()-api.pointer.moved < 120
  api.now()      高精度时间戳(ms)
  api.rand(a,b)  返回 [a,b) 随机数
  api.randInt(a,b) 返回 [a,b] 随机整数
  api.TOP        顶层 window（需要 setTimeout/devicePixelRatio 等时用 api.TOP.xxx）

注意：
- 不要自己创建 canvas 或往 document 加东西；只画在 api.ctx 上。
- 坐标用 CSS 像素（0..api.width / 0..api.height），dpr 已由宿主处理。

──────────────────────────────────────────────
三、特效实例：你的 code 必须 return 的对象
──────────────────────────────────────────────
return {
  frame: function(dt){ ... },   ← 必须。每帧调用一次，dt=距上一帧毫秒数
                                   （已被限制在 0..50ms，用 dt/16.6 当作帧步长 f）
  resize: function(w,h){ ... },  ← 可选。画布尺寸变化时调用
  clear:  function(){ ... },     ← 可选。特效被关闭/切走时调用，
                                   建议在这里 ctx.clearRect 并清空你的粒子数组
  destroy:function(){ ... }      ← 可选。特效被删除时调用，做最终清理
}

帧循环由宿主统一驱动（requestAnimationFrame）。多个特效同时启用时各自有
独立 canvas，互不干扰。

──────────────────────────────────────────────
四、画布清屏 / 拖尾两种范式
──────────────────────────────────────────────
A) 瞬时型（每帧重画，无残留，如水波纹）：
   frame 开头 ctx.clearRect(0,0,api.width,api.height); 再画当前所有粒子。

B) 拖尾型（要留下缓慢消退的痕迹，如玻璃上流淌的雨水）：
   不要整屏清除，而是每帧用「擦除一点点」制造渐隐：
     ctx.globalCompositeOperation='destination-out';
     ctx.fillStyle='rgba(0,0,0,'+Math.min(0.4,0.06*f)+')';  // f=dt/16.6
     ctx.fillRect(0,0,W,H);
     ctx.globalCompositeOperation='source-over';
   然后正常 source-over 画粒子。这样旧像素会随时间淡出，形成水痕拖尾。

──────────────────────────────────────────────
四点五、想要 WebGL / 着色器特效（如玻璃折射雨）
──────────────────────────────────────────────
api.canvas 已被宿主取了 2D 上下文，不能再在它上面取 WebGL。若要用 WebGL/
着色器（例如移植 Shadertoy 的折射雨），做法是：
1) 在 frame 里自建一个隐藏的离屏 canvas：
     var glc = api.canvas.ownerDocument.createElement('canvas');
     var gl = glc.getContext('webgl') || glc.getContext('experimental-webgl');
   （只建一次，缓存起来；拿不到 gl 就优雅退化或直接 return。）
2) 把 glc 尺寸设为 api.width*api.dpr × api.height*api.dpr，gl.viewport 同步。
3) 在 glc 上跑你的着色器渲染，然后回到 2D 画布把结果贴上去：
     api.ctx.clearRect(0,0,api.width,api.height);
     api.ctx.drawImage(glc, 0, 0, api.width, api.height);
要折射「底图」(VN 背景)：读 api.canvas.ownerDocument.getElementById('vnm-bg')
的 getComputedStyle(...).backgroundImage 取出 url，用 new Image()
（crossOrigin='anonymous'）加载成纹理；底图是 blob/dataURL(同源)时可用，跨域
无 CORS 会失败，要准备退化分支。Shadertoy 的 iChannel0 即此底图纹理，
textureLod 在 WebGL1 用 texture2D 代替。要「只显示水滴、其余透明」就把
gl_FragColor.a 设为水滴遮罩(drop mask)，非水滴处 alpha=0，从而露出真实底图与
UI——这样既有折射又不糊底图（不要 fog）。

──────────────────────────────────────────────
五、颜色铁律：只能顺色，禁止任何彩色
──────────────────────────────────────────────
整个 VN 是液态玻璃顺色风格。特效只能用白/灰/黑的不同透明度，
即 rgba(255,255,255,a) / rgba(0,0,0,a)。严禁出现任何有色相的颜色
（蓝、青、彩色渐变等一律禁止）。水、光、雾都靠「白色高光 + 暗边阴影 +
透明度」来表现，而不是靠颜色。

──────────────────────────────────────────────
六、参数实时可调（务必）
──────────────────────────────────────────────
所有「密度/大小/强度/频率」等都做成 params 滑块，frame 里每帧读 api.params。
约定：把「频率/数量」类参数允许 0 = 关闭该子功能（例如水波纹的随机频率
设为 0 就不再自动冒泡）。这样用户在一个特效内就能开关子效果。

──────────────────────────────────────────────
七、性能与健壮
──────────────────────────────────────────────
1. 给粒子数组设上限（如 if(arr.length>800) arr.shift();），雨量大时也不卡。
2. 一切按 dt 缩放（用 f=dt/16.6），避免不同刷新率下快慢不一。
3. 不要抛异常；宿主有 try/catch，但你也应自我保护（api.width 可能为 0，
   此时直接 return）。
4. 不依赖外部库、不发网络请求、不读写 localStorage。

──────────────────────────────────────────────
八、最小示例（飘雪，可直接当模板改）
──────────────────────────────────────────────
{
  "vnmWeatherEffect": true,
  "name": "飘雪",
  "params": [
    {"key":"amount","label":"雪量","min":1,"max":10,"default":4,"step":1}
  ],
  "code": "(function(api){var s=[];function frame(dt){var W=api.width,H=api.height;if(!W)return;var f=dt/16.6;var ctx=api.ctx;ctx.clearRect(0,0,W,H);var amt=api.params.amount||4;if(s.length<amt*40&&Math.random()<amt*0.05){s.push({x:api.rand(0,W),y:-5,r:api.rand(1,3),vx:api.rand(-0.3,0.3),vy:api.rand(0.4,1.2)});}for(var i=s.length-1;i>=0;i--){var p=s[i];p.x+=p.vx*f;p.y+=p.vy*f;if(p.y>H+5){s.splice(i,1);continue;}ctx.fillStyle='rgba(255,255,255,'+(0.7)+')';ctx.beginPath();ctx.arc(p.x,p.y,p.r,0,6.2832);ctx.fill();}}function clear(){api.ctx.clearRect(0,0,api.width,api.height);s=[];}return{frame:frame,clear:clear,resize:clear};})"
}

──────────────────────────────────────────────
九、固定 / 随机（由宿主负责，你不用管）
──────────────────────────────────────────────
- 用户可把某个特效标「固定」：随机模式下它也始终显示。
- 随机模式：宿主每隔一段时间随机挑若干个「非固定」特效组合显示。
- 这些都在天气 App 里完成，你的特效文件无需为此写任何代码——只要按本指南
  写好单个特效即可被组合。

──────────────────────────────────────────────
十、交付自查
──────────────────────────────────────────────
1. JSON.parse 能通过；vnmWeatherEffect:true、name、code 齐全。
2. code 是被括号包裹的函数表达式，return 了含 frame 的实例对象。
3. 只用顺色（白/灰/黑 + 透明度），无任何彩色。
4. 所有可调项都在 params 里，frame 每帧读取 api.params。
5. 有 clear（关闭时清屏并清空数组），粒子数组有上限。
