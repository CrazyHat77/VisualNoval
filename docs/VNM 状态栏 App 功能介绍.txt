# VNM 状态栏 App 功能介绍

VNM 状态栏是一款为 Visual Novel 功能系统开发的正则抓取与 HTML 的预览工具。

它可以自动读取 SillyTavern聊天消息中的指定标签内容，调用用户导入的正则规则完成文本替换，并将替换结果渲染成可交互的 HTML 状态栏。适用于状态栏等多种正则前端，同时也适配纯文字状态栏，和纯HTML（例如HTML小剧场）

## 🎯 核心功能

1. 自动抓取酒馆消息
App 可以直接读取当前酒馆聊天记录，无需手动复制 AI 回复。

支持：
- 设置自动读取最近多少条消息
- 指定一个或多个聊天楼层
- 使用楼层范围，例如 `5-8`
- 切换聊天存档时自动重新抓取
- 检测到新消息后自动更新状态栏

如果没有指定楼层，App 会按照“最近消息数”自动读取；指定楼层后，则优先读取所填写的楼层。

2. 自定义 Tag 抓取
用户可以自由添加需要识别的标签

支持：
- 同时配置多个 Tag
- 同一条消息中抓取多个标签区块
- 从多个聊天楼层抓取状态栏
- 识别同名标签的多次出现
- 显示每个标签对应的来源楼层

## 🤖正则管理

3. 导入酒馆正则 JSON
App 可以直接导入常见的 SillyTavern 正则 JSON 文件
同一个 App 中可以保存多条正则规则。

4. 多正则同时执行
抓取状态栏时，App 会让所有已导入的有效正则依次参与匹配。

支持：
- 为不同 Tag 配置不同状态栏
- 同时显示多个状态栏
- 将不同作者制作的正则集中管理
- 一次抓取多个 HTML 组件


## 👾HTML 渲染与交互

5. 可交互状态栏
如果状态栏本身包含 JavaScript，App 可以保留并运行其全部交互逻辑

6. 酒馆输入桥接
部分状态栏会在点击选项后，将内容写入酒馆输入框或直接触发发送。
若当前为 Visual Novel全屏状态，则会写入全屏对话框。

## 🖋️ 状态内容修改

7. 编辑抓取到的状态栏原文
App 可以直接编辑已经抓取的 Tag 内部文本。

支持：
- 查看当前抓到的标签区块
- 修改文本
- 保存并刷新 HTML
- 将修改同步回酒馆聊天消息

此功能适合查看修正 AI 输出中的格式错误

## 📂 记录管理

8. 按聊天存档保存记录
状态栏记录会按照当前聊天存档分别保存。

支持：
- 查看历史状态栏
- 恢复历史预览
- 删除单/多条记录
- 清空当前/所有存档缓存
- 设置最多保留多少条记录

正则和 Tag 配置不会因为清理历史记录而被删除。

## 🫧兼容与降级

9. 多种内容格式兼容
App 可以处理：
- 完整 HTML 文档
- 带 `DOCTYPE` 的页面
- HTML 代码围栏
- 嵌套的 `<html><body>` 结构
- 普通 HTML 片段
- 只包含 CSS 和组件的模板
- 带 JavaScript 的交互页面
- 多个 HTML 结果组合显示

10. 脚本安全开关
设置中提供“保留 HTML 脚本预览”开关。

- 开启：保留状态栏脚本和交互功能
- 关闭：移除 `<script>` 与内联事件，作为静态 HTML 显示

由于交互模式会执行正则文件内附带的 JavaScript，建议只导入来源可信的正则文件。

# 使用方法

1. 打开 VNM 功能系统中的“状态栏”。
2. 点击“设置”。
3. 添加需要抓取的 Tag 名称。
4. 导入酒馆正则 JSON，或者手动新建正则。
5. 根据需要设置抓取楼层。
6. 返回预览页，点击顶部“重新抓取”按钮。
7. App 会自动读取消息、执行正则并显示 HTML。
8. 后续酒馆产生新消息时，状态栏会自动更新。
